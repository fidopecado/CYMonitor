Four screens, one glance

Built for a desk, not a debug console.

Every pixel is drawn with TFT_eSPI primitives at 480 × 320. The interface is fully touch-driven: tabs in the header, tappable cards, a scrollable theme gallery and a physical BOOT-key shortcut.

From data.json to pixels

A tiny, self-hosted telemetry pipeline.

LibreHardwareMonitor exposes a JSON tree on your PC. The ESP32 walks that tree by SensorId, parses values with ArduinoJson on a background task, and paints only the regions that changed. Wi-Fi credentials and the endpoint URL are captured through a captive portal.

  1. 01

    Flash the board

    PlatformIO builds for esp32dev with the huge_app.csv partition so the embedded GIF fits.

  2. 02

    Serve the sensor tree

    Enable Options → Remote Web Server → Run in LibreHardwareMonitor; it listens on port 8085.

  3. 03

    Join the captive portal

    Connect to CYD-MONITOR-AP, pick your network, paste the JSON URL. Done.

void httpFetchTask(void *pv) {
  for (;;) {
    if (currentPage == 0 &&
        WiFi.status() == WL_CONNECTED) {
      HTTPClient http;
      http.begin(serverUrl);
      http.setTimeout(2000);

      int httpCode = http.GET();
      if (httpCode == HTTP_CODE_OK) {
        JsonDocument doc;
        deserializeJson(doc, http.getStream(),
          DeserializationOption::NestingLimit(30));

        currentCpuTemp = parseFloatValue(
          findSensorBySensorId(doc.as<JsonVariant>(), CPU_TEMP_ID));
        currentGpuCore = parseFloatValue(
          findSensorBySensorId(doc.as<JsonVariant>(), GPU_CORE_ID));
        currentRamLoad = parseFloatValue(
          findSensorBySensorId(doc.as<JsonVariant>(), RAM_LOAD_ID));

        pushHistory(cpuHistory, currentCpuTemp);
        dataUpdated = true;
      }
      http.end();
      vTaskDelay(pdMS_TO_TICKS(400));
    }
  }
}

Bill of materials

One board. One cable.

The ESP32-3248S035 "CYD" bundles an ESP32, a 3.5-inch 480 × 320 ST7796 panel, resistive touch and an LDR in a single yellow PCB. No soldering, no extra sensors.
