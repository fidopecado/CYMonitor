Four screens, one glance

Built for a desk, not a debug console.

Every pixel is drawn with TFT_eSPI primitives at 480 × 320. The interface is fully touch-driven: tabs in the header, tappable cards, saved-network profiles, a three-page theme gallery and a physical BOOT-key shortcut.

Hardware monitor

Adaptive CPU and GPU temperatures, hotspot, loads, fan RPM, package power, VRAM and RAM — with trend badges, 40-sample sparklines and a clear no-data state.

From data.json to pixels

A tiny, self-hosted telemetry pipeline.

LibreHardwareMonitor exposes a JSON tree on your PC. The ESP32 walks that tree once, classifies each hardware branch as CPU, GPU or RAM, and picks the strongest sensor by type and label. Wi-Fi credentials and the JSON URL are saved per network, so switching machines is a single tap.

  1. 01

    Flash the board

    PlatformIO builds for esp32dev with the huge_app.csv partition. The GIF was removed, so the firmware now uses far less flash.

  2. 02

    Serve the sensor tree

    Enable Options → Remote Web Server → Run in LibreHardwareMonitor; it listens on port 8085.

  3. 03

    Join the captive portal

    Connect to CYD-MONITOR-AP, pick your network, paste the JSON URL. The profile is saved for next time.

void httpFetchTask(void *pv) {
  for (;;) {
    if (pageActive(0) &&
        WiFi.status() == WL_CONNECTED) {
      HTTPClient http;
      http.begin(getServerUrl());
      http.setTimeout(2000);

      if (http.GET() == HTTP_CODE_OK) {
        JsonDocument doc;
        deserializeJson(doc, http.getStream(),
          DeserializationOption::NestingLimit(30));

        ScanResult scan;
        scanSensorNode(doc.as<JsonVariant>(),
          HW_OTHER, -1, scan);
        finalizeScan(scan);
        commitLiveData(scan.data);
        pushHistory(cpuHistory, scan.data.cpuTemp);
      }
      http.end();
      vTaskDelay(pdMS_TO_TICKS(400));
    }
  }
}

Bill of materials

One board. One cable.

The ESP32-3248S035 "CYD" bundles an ESP32, a 3.5-inch 480 × 320 ST7796 panel, resistive touch and an LDR in a single yellow PCB. No soldering, no extra sensors.
