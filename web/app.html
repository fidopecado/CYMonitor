WHERE DO I FIND THIS URL?
  1. Run LibreHardwareMonitor on the PC that owns the sensors.
  2. Open Options → Remote Web Server → Run.
  3. Open http://<pc-ip>:8085/data.json on this network.
  4. Allow port 8085 through Windows Firewall if needed.

LibreHardwareMonitor sends Access-Control-Allow-Origin: * by default.
